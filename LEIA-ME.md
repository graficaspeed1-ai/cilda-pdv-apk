# Cilda Biju – Frente de Caixa (APK)

1. Crie um repositório no GitHub (ex.: `cilda-pdv`).
2. Envie TODOS os arquivos desta pasta (inclusive a pasta oculta `.github`).
3. Aba **Actions** > **Build APK** > **Run workflow** (ou roda sozinho ao enviar).
4. Em uns 5 a 10 min, baixe **cilda-biju-pdv-apk** em *Artifacts*, instale `app-debug.apk` no tablet (permita "fontes desconhecidas").

Os dados (vendas do dia) ficam salvos no próprio tablet. Para testar antes: abra `www/index.html` no navegador.
